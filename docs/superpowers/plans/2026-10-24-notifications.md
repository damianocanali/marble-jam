# Notifications Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Local notifications for season starts, holidays ending soon and a come-back nudge, with a friendly opt-in after the first challenge win and a switch on the Account screen.

**Architecture:** A pure planner (`Reminders.plan`) turns the date, the season windows and the player's progress into a list of `Reminder`s. A `@MainActor` `ReminderScheduler` (shared instance, injectable notification center for tests) books them with `UNUserNotificationCenter` each time the app goes to the background, and handles permission. Two small UI pieces use it: a card after the first challenge win (`ContentView`) and a switch (`AccountView`).

**Tech Stack:** Swift, SwiftUI, UserNotifications, XCTest. Project generated by xcodegen (`xcodegen generate` after adding files).

**Spec:** `docs/superpowers/specs/2026-10-24-notifications-design.md`

## Global Constraints

- Local notifications only. No push, no server, no new privacy manifest entries; App Privacy stays "Data Not Collected".
- Every notification fires at 16:30 local time.
- Season start on a window's first day; ending soon 3 days before its last day; come-back 4 days after the app last went to the background.
- Ending soon is skipped when the holiday is done (`progress.holidaysDone()` contains it) or when it would fall on or before the season start.
- Come-back is dropped when a season notification is within 1 day of it.
- Never more than 64 pending requests; nothing in the past.
- Never about purchases. DEBUG capture launches (`CaptureMode.current.isActive`) never show the card and never book anything.
- `UserDefaults` keys: `notifications.on` (Bool; false = player turned it off), `notifications.asked` (Bool; the card was answered).
- Build/test: `xcodebuild test -project MarbleJam.xcodeproj -scheme MarbleJam -destination 'platform=iOS Simulator,id=3216599D-C09E-4E00-931B-AE5B16A8228F'` (another Claude session may use the simulator: never run two test runs at once).

## Review Focus

- A season start that is today but after 16:30 must not be booked (it is in the past); tested in Task 1 (`testNothingInThePast`).
- New Year's window crosses the year (Dec 31 – Jan 6): its start and ending soon must both appear when planning from December; tested in Task 1 (`testNewYearAcrossTheYearEnd`).
- A player who turned the switch off must get nothing booked even though iOS still allows it; tested in Task 2 (`testNothingBookedWhenTurnedOff`).
- The card must appear only once, even after many wins, and never after an Open Play run (no challenge); tested in Task 2 (`testOfferOnlyOnceAfterAChallengeWin`).
- Rescheduling replaces old requests instead of piling up (a player who opens the app daily); tested in Task 2 (`testRescheduleReplacesPending`).

```swift
import Foundation

/// A local notification to book: when, and what it says.
struct Reminder: Equatable {
    let id: String
    let date: Date
    let title: String
    let body: String
}

/// Works out the notifications for the next year: each holiday's start, a few days before it ends, and one come-back
/// nudge after a few days away. Pure, so it can be tested with fixed dates.
enum Reminders {
    static let hour = 16, minute = 30, endingDaysBefore = 3, comeBackAfterDays = 4

    static func plan(now: Date, lastPlayed: Date, progress: ChallengeProgress, calendar: Calendar) -> [Reminder] {
        let horizon = calendar.date(byAdding: .day, value: 366, to: now)!
        let done = progress.holidaysDone()
        func at(_ d: Date) -> Date { calendar.date(bySettingHour: hour, minute: minute, second: 0, of: d)! }
        var seasonal: [Reminder] = []
        let year = calendar.component(.year, from: now)
        for s in Seasons.all {
            for y in (year - 1)...(year + 1) {
                let w = s.window(y, calendar)
                let start = at(w.first), ending = at(calendar.date(byAdding: .day, value: -endingDaysBefore, to: w.last)!)
                let levels = Challenges.holidayIDs(s.id).count
                seasonal.append(Reminder(id: "start-\(s.id)-\(y)", date: start, title: s.banner, body: "New songs and \(levels) holiday levels."))
                if ending > start, !done.contains(s.id) {
                    seasonal.append(Reminder(id: "ending-\(s.id)-\(y)", date: ending, title: "\(s.emoji) \(s.title)",
                                             body: "Last few days for the \(s.title) levels \(s.emoji)"))
                }
            }
        }
        seasonal = seasonal.filter { $0.date > now && $0.date <= horizon }
        var all = seasonal
        let back = at(calendar.date(byAdding: .day, value: comeBackAfterDays, to: lastPlayed)!)
        if back > now, !seasonal.contains(where: { abs($0.date.timeIntervalSince(back)) <= 24 * 3600 }) {
            all.append(Reminder(id: "comeback", date: back, title: "Marble Beats", body: comeBackText(progress)))
        }
        return Array(all.sorted { $0.date < $1.date }.prefix(64))
    }

    /// Names the first main world with stars still to win, or a general nudge when they're all won.
    static func comeBackText(_ progress: ChallengeProgress) -> String {
        for w in 1...5 {
            let ids = Challenges.mainIDs.filter { $0.hasPrefix("w\(w)-") }
            let left = ids.count * 3 - progress.totalStars(ids: ids)
            if left > 0 { return "Your marble is waiting: \(left) \(left == 1 ? "star" : "stars") left in World \(w) ⭐" }
        }
        return "Your marble misses you! Come make some music 🎵"
    }
}
```

```swift
import SwiftUI
import UserNotifications

/// What the scheduler needs from the notification system (a fake stands in for it in tests).
protocol ReminderCenter {
    func status() async -> UNAuthorizationStatus
    func requestAuthorization() async -> Bool
    func replacePending(with requests: [UNNotificationRequest]) async
    func removeAllPending()
}

struct SystemReminderCenter: ReminderCenter {
    private var center: UNUserNotificationCenter { .current() }
    func status() async -> UNAuthorizationStatus { await center.notificationSettings().authorizationStatus }
    func requestAuthorization() async -> Bool { (try? await center.requestAuthorization(options: [.alert, .sound])) ?? false }
    func replacePending(with requests: [UNNotificationRequest]) async {
        center.removeAllPendingNotificationRequests()
        for r in requests { try? await center.add(r) }
    }
    func removeAllPending() { center.removeAllPendingNotificationRequests() }
}

/// Books `Reminders.plan` with iOS and handles permission. Never asks by itself: only the card after the first
/// challenge win and the Account switch do.
@MainActor final class ReminderScheduler: ObservableObject {
    static let shared = ReminderScheduler(center: SystemReminderCenter(), defaults: .standard)

    @Published private(set) var isOn = false
    private let center: ReminderCenter
    private let defaults: UserDefaults
    private let onKey = "notifications.on", askedKey = "notifications.asked"

    init(center: ReminderCenter, defaults: UserDefaults) { self.center = center; self.defaults = defaults }

    private var turnedOff: Bool { defaults.object(forKey: onKey) as? Bool == false }
    private var captures: Bool {
        #if DEBUG
        CaptureMode.current.isActive
        #else
        false
        #endif
    }

    func refresh() async {
        let s = await center.status()
        isOn = !turnedOff && (s == .authorized || s == .provisional)
    }

    /// Replaces everything booked with a fresh plan; the player was last here `now`.
    func reschedule(progress: ChallengeProgress, now: Date = Date()) async {
        await refresh()
        guard isOn, !captures else { return }
        let requests = Reminders.plan(now: now, lastPlayed: now, progress: progress, calendar: .current).map { r in
            let content = UNMutableNotificationContent()
            content.title = r.title; content.body = r.body; content.sound = .default
            let when = Calendar.current.dateComponents([.year, .month, .day, .hour, .minute], from: r.date)
            return UNNotificationRequest(identifier: r.id, content: content, trigger: UNCalendarNotificationTrigger(dateMatching: when, repeats: false))
        }
        await center.replacePending(with: requests)
    }

    /// Apple's prompt (from the card's "Yes please"); books right away if allowed.
    func askPermission(progress: ChallengeProgress) async {
        if await center.requestAuthorization() { defaults.set(true, forKey: onKey) }
        await reschedule(progress: progress)
    }

    enum TurnOn { case on, openSettings, refused }

    /// The Account switch turned on: ask if never asked, point to Settings if the player said no before.
    func turnOn(progress: ChallengeProgress) async -> TurnOn {
        switch await center.status() {
        case .notDetermined:
            guard await center.requestAuthorization() else { await refresh(); return .refused }
        case .denied:
            return .openSettings
        default: break
        }
        defaults.set(true, forKey: onKey)
        await reschedule(progress: progress)
        return .on
    }

    func turnOff() {
        defaults.set(false, forKey: onKey)
        center.removeAllPending()
        isOn = false
    }

    /// The card shows once per install, after the celebration of a challenge won with at least one star.
    func shouldOffer(after c: Celebration, inChallenge: Bool) -> Bool {
        inChallenge && c.stars > 0 && !defaults.bool(forKey: askedKey) && !captures
    }

    func markOffered() { defaults.set(true, forKey: askedKey) }
}
```

Add `@ObservedObject private var reminders = ReminderScheduler.shared`. Insert before the `card("Privacy & help", …)`:

```swift
                    card("Notifications", icon: "bell") {
                        Toggle(isOn: Binding(get: { reminders.isOn }, set: { on in
                            Task {
                                if on {
                                    if await reminders.turnOn(progress: progress) == .openSettings,
                                       let url = URL(string: UIApplication.openNotificationSettingsURLString) {
                                        await UIApplication.shared.open(url)
                                    }
                                } else { reminders.turnOff() }
                            }
                        })) { line("Holiday news and a gentle reminder now and then. Never at night, never about the store.") }
                        .tint(.cyan)
                    }
```

and on the outer view add `.task { await reminders.refresh() }`, plus `.onChange(of: phase) { _, p in if p == .active { Task { await reminders.refresh() } } }` with `@Environment(\.scenePhase) private var phase` (so coming back from Settings updates the switch).
